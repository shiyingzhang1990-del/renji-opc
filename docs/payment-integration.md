# 支付、冻结与分阶段结算设计

## 核心原则

壬镜科技是交易平台，不应把买家支付金额直接沉淀在公司普通银行账户，
也不应在没有支付业务许可的情况下自行形成“余额”“钱包”“备付金”或资金池。

正式产品应接入：

- 微信支付平台型收付、二级商户与分账能力
- 支付宝面向互联网平台的商家进件、支付、待结算与分账能力
- 商业银行的平台资金存管/分账产品
- 其他持牌支付机构的平台型资金解决方案

## 业务数据库保存什么

可保存：

- 平台订单号
- 支付机构交易号
- 支付状态
- 金额
- 退款金额
- 分账金额
- 时间
- 回调摘要
- 签名验证结果
- 幂等键
- 对账状态

不应保存：

- 银行卡完整卡号
- 支付密码
- CVV
- 未经许可的支付账户敏感信息
- 可直接用于盗刷或越权支付的凭据

## 推荐支付状态

```text
CREATED
→ PAYING
→ FROZEN / PENDING_SETTLEMENT
→ PARTIALLY_RELEASED
→ RELEASED

异常分支：
FAILED
REFUNDING
REFUNDED
CLOSED
```

## 生产级必做

1. 支付回调验签
2. 幂等
3. 金额和订单号校验
4. 回调重放保护
5. 状态机
6. 事务和消息一致性
7. 日终对账
8. 差错处理
9. 退款与分账回退
10. 争议期间冻结
11. 审计日志
12. 密钥轮换
13. 最小权限
14. 沙箱与生产隔离

## 分阶段结算

订单总金额 10,000 元，平台费率 8%，三个里程碑：

- 需求与原型：2,000 元
- 正式开发：5,000 元
- 上线与验收：3,000 元

每次验收后分别向支付机构发起释放：

```text
商家结算额 = 里程碑金额 × (1 - 平台费率)
平台服务费 = 里程碑金额 × 平台费率
```

实际收费还需考虑支付机构手续费、税费、退款和优惠。

## 自动验收

可设置：

- 买家主动验收
- 商家提交后 5 个自然日无异议自动验收
- 高风险品类不自动验收
- 金额超过阈值时需人工复核
- 争议一旦发起立即停止自动释放

自动验收必须在订单页面和合同中显著告知。
